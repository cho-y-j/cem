# CEM 프로젝트 최종 보고서

> **작성일**: 2025년 12월 5일
> **프로젝트명**: 건설현장 장비·인력 통합관리 시스템 (CEM)
> **버전**: 1.0.0

---

## 1. 프로젝트 개요

### 1.1 목적
건설 현장에서 운영되는 임대 장비와 관련 인력을 통합 관리하여 안전하고 효율적인 현장 운영을 지원하는 웹/모바일 플랫폼 개발

### 1.2 개발 기간
- 착수: 2025년 10월
- 완료: 2025년 12월 5일

### 1.3 주요 이해관계자
| 역할 | 설명 |
|------|------|
| Owner (장비 임대사업자) | 장비/인력 등록, 서류 관리 |
| BP (협력사) | 반입요청 검토, 작업 확인서 승인 |
| EP (운영사) | 최종 승인, 전체 모니터링 |
| Worker (운전자) | 모바일 앱으로 작업 확인서 제출, 출퇴근 관리 |
| Inspector (안전점검원) | 장비 안전점검 수행 |
| Admin (관리자) | 시스템 설정, 마스터 데이터 관리 |

## 3. 구현 기능

### 3.1 핵심 기능

#### 반입요청 워크플로우 (3단계 승인)
```
Owner 생성 → BP 검토/승인 → EP 최종 승인 → 투입(Deployment) 생성
```
- 상태: bp_draft → bp_requested → owner_reviewing → owner_approved → bp_reviewing → bp_approved → ep_reviewing → ep_approved
- 반려 시 사유 기록
- 작업 계획서 첨부 지원

#### 서류 관리 시스템
- 장비/인력 유형별 필수 서류 정의
- 서류 업로드 및 PDF 미리보기
- 만료일 추적 (30일, 7일, 당일 알림)
- 운전면허 자동 검증 (RIMS API)
- OCR 자동 추출 (Google Vision)

#### 투입 관리 (Deployment)
- 장비 + 운전자 + 유도원 투입 관리
- 투입 기간 연장 기능
- 작업자 변경 이력 관리
- 작업 구역 배정

#### 안전점검 시스템
- JSON 기반 동적 점검표 템플릿
- 장비 종류별 맞춤 점검항목
- 운전자 일일 자가점검
- 안전점검원 정기 점검
- 점검 이력 및 통계

### 3.2 모바일 기능 (Worker/Inspector)

| 기능 | 설명 |
|------|------|
| PIN 로그인 | 4자리 PIN 인증 |
| 생체 인증 | WebAuthn (지문/Face ID) |
| GPS 출퇴근 | 위치 기반 체크인/아웃 |
| NFC 태그 | 장비별 NFC 스캔 |
| 작업 확인서 | 일일 작업 내용 제출 |
| 푸시 알림 | Firebase FCM |

### 3.3 관리자 기능 (Admin)

- 사용자 관리 (역할별)
- 회사 관리 (Owner/BP/EP)
- 장비 유형 관리
- 인력 유형 관리
- 안전점검표 템플릿 관리
- 작업 구역 관리

### 3.4 대시보드

| 대시보드 | 대상 | 주요 정보 |
|----------|------|-----------|
| Admin | 관리자 | 전체 현황, 만료 서류 |
| Owner | 임대사업자 | 내 장비/인력, 반입요청 |
| BP/EP | 협력사/운영사 | 승인 대기, 투입 현황 |
| Worker | 운전자 | 내 투입, 작업 확인서 |
| Inspector | 점검원 | 점검 일정, 최근 점검 |
