### 2. NFC 플러그인 교체 및 수정

#### 문제
- 기존 `@exxili/capacitor-nfc` 플러그인이 네이티브 Android 앱에서 로드되지 않음
- "NFC 플러그인을 사용할 수 없습니다" 오류 발생
- NFC 버튼 비활성화 상태 유지

#### 해결
1. **플러그인 교체**
   - `@exxili/capacitor-nfc` 제거
   - `@capgo/capacitor-nfc@7.0.10` 설치 (최신 업데이트: 2025-11-24)
   - Capacitor 7 정식 지원

2. **nfcHelper.ts 수정**
   - API 변경에 맞춰 코드 수정:
     - `Nfc` → `CapacitorNfc`
     - `isEnabled()` → `getStatus()` (result.status === 'NFC_OK')
     - `startScanSession()` → `startScanning()`
     - `stopScanSession()` → `stopScanning()`
     - 이벤트: `nfcTag` → `nfcEvent`

3. **NFC 태그 ID 형식 통일**
   - 앱과 웹에서 동일한 형식 사용
   - 형식: 소문자 hex, 콜론 구분 (예: `04:a3:b2:c1:d5:e6:f7`)
   - 앱: 바이트 배열을 hex로 변환 시 소문자 사용
   - 웹: serialNumber를 소문자로 변환, 하이픈을 콜론으로 변환

#### 수정 파일
- `client/src/utils/nfcHelper.ts`
- `package.json` (의존성 변경)
