const [activeTab, setActiveTab] = useState<"review" | "history">("review");

### 2. 작업 현황 & 위치 모니터링 통합

**파일**: `client/src/pages/WorkMonitoring.tsx`

#### Before (기존)
- `/work-monitoring`: 작업 현황만 (경과 시간, 휴식 경고)
- `/location-tracking`: 실시간 위치 추적 (지도, 마커)
- 이동 분석 기능은 LocationTracking에만 존재

#### After (개선)
- `/work-monitoring`: **3개 탭으로 통합**
  - **탭 1: 작업 현황** - 작업 시간, 휴식 경고, 근로기준법 정보
  - **탭 2: 실시간 위치** - Google Maps 기반 위치 추적 (10초 자동 새로고침)
  - **탭 3: 이동 분석** - 이동 경로 분석, 체류 지점, 통계

#### 주요 개선 사항
```typescript
// 탭 상태 관리
const [activeTab, setActiveTab] = useState<"monitoring" | "location" | "analysis">("monitoring");

// 실시간 위치 탭 - 10초 자동 새로고침
useEffect(() => {
  if (activeTab !== "location") return;
  const interval = setInterval(() => refetch(), 10000);
  setRefreshInterval(interval);
  return () => { if (interval) clearInterval(interval); };
}, [refetch, activeTab]);

// 조건부 쿼리 활성화
const { data: locationData } = trpc.location.getAllActive.useQuery(
  filters,
  { enabled: activeTab === "location" }
);

const { data: analysisData } = trpc.location.analyzeHistory.useQuery(
  { workerId, startDate, endDate },
  { enabled: !!analysisWorkerId && activeTab === "analysis" }
);
```

#### Google Maps 통합
- **마커 아이콘**: 작업 상태별 색상 + 차종별 모양
- **Polyline**: 이동 경로 시각화 (빨간 선)
- **마커 범례**: 지도 우측 상단 오버레이
- **작업 상태별 색상**:
  - 🟢 작업중: `#10B981`
  - 🟡 휴식중: `#F59E0B`
  - 🔵 연장작업: `#3B82F6`
  - ⚪ 작업종료: `#9CA3AF`

#### 이동 분석 기능
- 총 이동 거리 (km)
- 평균 속도 / 최대 속도 (km/h)
- 총 시간 (시간/분)
- 체류 지점 목록 (좌표, 시간)
