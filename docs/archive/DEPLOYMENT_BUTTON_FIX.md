# 투입 관리 버튼 표시 문제 해결 가이드

## 문제 상황
- Owner: 연장, 운전자 교체, 종료 버튼이 안 보임
- BP: 승인 버튼만 나왔는데 에러남, 유도원 교체 버튼 안 보임

## 진단 결과

### ✅ 데이터베이스 상태 확인 완료
```
pending_bp: 2개 (BP 승인 대기)
active: 3개 (투입중)
```

### ✅ enum 타입 확인 완료
`pending_bp` 값이 deployment_status enum에 존재함

### ✅ 코드 로직 확인 완료
- BP 승인 버튼: `deployment.status === "pending_bp"` ✅
- 연장/교체/종료 버튼: `deployment.status === "active" || "extended"` ✅

## 해결 방법

### 1단계: 서버 재시작 (필수!)

```bash
# 현재 실행 중인 dev 서버 종료 (Ctrl+C)
# 그리고 다시 시작
pnpm dev
```

**중요**: 코드 변경 후 서버를 재시작하지 않으면 변경사항이 반영되지 않습니다!

### 2단계: 브라우저 강력 새로고침 (필수!)

**Windows/Linux**: `Ctrl + Shift + R`
**Mac**: `Cmd + Shift + R`

일반 새로고침(F5)이 아닌 **캐시 무시 새로고침**을 해야 합니다!

### 3단계: 브라우저 콘솔 확인

1. F12 눌러서 개발자 도구 열기
2. Console 탭 확인
3. 에러 메시지가 있으면 스크린샷 찍어주세요

### 4단계: 네트워크 탭 확인

1. F12 → Network 탭
2. 페이지 새로고침
3. `deployments.list` 요청 찾기
4. Response 탭에서 deployment 데이터 확인
   - `status` 필드가 제대로 있는지 확인
   - `"status": "active"` 또는 `"status": "pending_bp"` 형태인지 확인

## 예상되는 문제와 해결

### 문제 1: 서버가 재시작되지 않음
**증상**: 코드 변경했는데 버튼이 여전히 안 보임
**해결**: `Ctrl+C`로 완전히 종료 후 `pnpm dev` 재실행

### 문제 2: 브라우저 캐시 문제
**증상**: 서버 재시작했는데도 안 됨
**해결**:
1. `Ctrl + Shift + R` 강력 새로고침
2. 또는 개발자 도구(F12) 열고 Network 탭에서 "Disable cache" 체크

### 문제 3: BP 승인 시 workZoneId 필수 에러
**증상**: BP가 승인 버튼 눌렀는데 "작업 구역을 선택하세요" 에러
**원인**: Owner가 투입 등록할 때 작업 구역을 선택하지 않음
**해결**:
- Owner가 투입 등록 시 "작업 구역 (현장명 + GPS)" 필드를 필수로 선택
- BP 승인 다이얼로그에서도 작업 구역 필수 선택

### 문제 4: 버튼이 여전히 안 보임
**확인 사항**:
1. 투입 상태가 `active`인지 확인
   - `pending_bp` 상태에서는 BP 승인 버튼만 보임
   - `active` 상태여야 연장/교체/종료 버튼 보임
2. BP로 로그인했을 때:
   - "승인대기" 탭: `pending_bp` 상태만 표시, 승인 버튼 보임
   - "투입중" 탭: `active` 상태 표시, 유도원 교체 버튼 보임

## 워크플로우 재확인

```
1. Owner: 투입 등록
   ↓
   status: "pending_bp" (BP 승인 대기)
   ↓
   [Owner/EP: 상세보기 버튼만 표시]
   [BP: 승인 버튼 표시]

2. BP: 승인 (유도원, 작업 구역, 단가 설정)
   ↓
   status: "active" (투입중)
   ↓
   [모든 버튼 표시됨!]
   - Owner/BP: 연장, 운전자 교체, 종료
   - BP: 유도원 추가/교체
   - EP: 안전점검원 지정

3. Owner/BP: 관리 작업
   ↓
   연장 → status: "extended"
   종료 → status: "completed"
```

## 여전히 안 되면?

다음 정보를 함께 알려주세요:
1. 서버 재시작 했는지 (Yes/No)
2. 브라우저 강력 새로고침 했는지 (Yes/No)
3. 브라우저 콘솔 에러 메시지 (스크린샷)
4. Network 탭에서 deployments.list Response (스크린샷)
5. 현재 로그인한 사용자 역할 (Owner/BP/EP)
6. 어떤 탭을 보고 있는지 ("전체"/"승인대기"/"투입중")
